# Digital Evidence Management System

## 📌 Project Overview

The Digital Evidence Management System is a Core Java based application designed to manage digital evidence securely and systematically.

The system provides different roles such as Admin, Investigator, and Auditor to manage users, cases, and digital evidence.

## 🎯 Objectives

- Manage users and their roles
- Create and manage cases
- Upload and store digital evidence
- Maintain evidence details
- Generate SHA-256 hash for evidence integrity
- Maintain audit information
- Use file handling for storing project data
- Apply Java OOP concepts in a real-world project

🔐 Evidence Integrity
The system uses SHA-256 hashing to generate a unique hash for digital evidence.
This helps verify whether an evidence file has been modified after it was uploaded.
